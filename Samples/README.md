# Samples

This directory contains sample projects which consume CSF.Screenplay.
These could be considered _as part of the documentation_.

* **CSF.Screenplay.Samples.SimpleToDoApp** is a small/simple "To Do List" web app which can be tested by Screenplay tests.
* **CSF.Screenplay.Samples.SimpleToDoAppTests** is a BDD test suite written using Reqnroll, Selenium and Screenplay to test the simple To Do List app.
